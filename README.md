# 🌻 Flores Amarillas – Sorpresa Interactiva

Una página web interactiva y animada desarrollada con HTML5, CSS3 y JavaScript puro. Diseñada como un detalle virtual para regalar flores amarillas, cuenta con una pantalla de bienvenida interactiva, música de fondo sincronizada, animaciones fluidas de tallos, pétalos y un efecto de partículas luminosas.

🔗 **Demostración:** [Ver proyecto](https://gof-of-souls.github.io/sorpresa/)

---

## ✨ Características

* **Diseño adaptativo (Mobile-First):** Optimizado para pantallas de smartphones (con soporte para `dvh` y `safe-area-inset`) y monitores de escritorio.
* **Jardín procedural dinámico:** Generación aleatoria de girasoles y tulipanes variados en altura, inclinación y escala.
* **Música ambiental integrada:** Reproducción de audio automática tras la interacción del usuario en la pantalla de bienvenida.
* **Interacción en tiempo real:** Botón **«✨ Florecer»** para detonar ráfagas de chispas luminosas.
* **Cero dependencias:** No requiere librerías externas ni frameworks pesados (Vanilla JS y CSS moderno).

---

## 🛠️ Tecnologías utilizadas

* **HTML5:** Estructura semántica y contenedores de audio.
* **CSS3:** Animaciones con `@keyframes`, degradados radiales/lineales, `clip-path` para pétalos y variables CSS (`var(--...)`).
* **JavaScript:** Manipulación del DOM, cálculo procedural de posiciones y gestión de eventos táctiles y de clic.
